# 边界与限制

## 平台验证

- 当前只在 **Windows** 上做过真实钥匙串 E2E。
- macOS/Linux 的真实 Keychain/Secret Service 未实机验证；CI 矩阵只覆盖 typecheck、单测、构建与打包，不覆盖真实钥匙串。
- Linux 无 Secret Service 时可能退化为 keyutils（不跨重启）或不可用；请以 `wzvtc doctor` 为准。
- 无头/沙箱环境需要在 TTY 输入主密码；`vault exec` 尚未实现。

## 功能边界

- 学工：未实现附件、销假、留校申请；不做教务课表冲突检测。
- 第二课堂：未实现签到/签退；报名审批流与部分字段仍以真实响应为准。
- 志愿汇：只读；写入不在当前范围。
- 未实现 CAS/WebForms、MCP、`vault exec`、`write_policy=human`、Vault 导出/恢复。
- 没有多用户、服务端、账号托管、定时任务。

## 稳定性

- 上游系统没有面向个人的官方 API，页面/JSON 可能变化。
- 学工链接的 TTL/失效方式尚未完全确认，且实测可重放。
- 第三方平台可能限频或阻断；程序会停止，不绕过。
- 学校/平台规则可能变化；使用前请确认合规。

## 非目标

- 不共享/售卖账号，不代他人操作，不批量操作。
- 不自动识别 CAPTCHA，不做反风控伪装，不突破访问控制。
- 不承诺 SLA；第三方非官方项目，与学校无隶属关系。
